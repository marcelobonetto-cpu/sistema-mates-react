## Instalar y ejecutar

Abrí Git Bash dentro de esta carpeta y ejecutá:

```bash
npm install
npm run dev
```

Después abrí:

```txt
http://localhost:5173
```

## Importante
Esta versión guarda la información en localStorage del navegador.
Sirve para usar y probar el sistema sin backend.

Más adelante se conecta a Supabase, Firebase, Node.js o PostgreSQL para guardar todo en una base de datos real.
